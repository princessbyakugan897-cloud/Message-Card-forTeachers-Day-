# Teachers' Day Message Card — Sir Randy Bello

A professional, minimal, animated Teachers' Day card made with HTML, CSS and JavaScript.

## Included
- Book-style 3D cover opening
- Inside photo + personalized message
- Final appreciation page
- Uploaded teacher photo already included
- Uploaded music already included
- Photo upload replacement
- Music upload replacement
- Editable teacher name
- Editable student/sender name
- Custom message editor
- Confetti animation
- Keyboard navigation with Left/Right arrow keys
- Responsive desktop/mobile layout

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/teacher-photo.jpg`
- `assets/teachers-day-song.m4a`

## How to run
Keep the folder structure intact, then double-click `index.html` or open it in a modern browser.

The music does not autoplay because modern browsers commonly block autoplay with sound. Click the round play button to start it.

## Personalization
You can change the teacher name, your name, photo, music and message directly in the card's customization section.
